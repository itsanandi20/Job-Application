# Static Job Application Website

A responsive **static job application webpage** built using **HTML and CSS**. This project focuses on clean structure, responsive design, accessibility, and modern HTML best practices.

## 🚀 Features

* Responsive design for desktop, tablet, and mobile devices
* Semantic HTML5 elements
* Clean and organized HTML structure
* Modern CSS styling
* Job application form with commonly used fields
* Form validation using HTML attributes
* Accessible form labels and input fields
* Mobile-friendly layout
* No JavaScript or backend required

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 📁 Project Structure

```text
job-application/
│
├── index.html
├── style.css
└── README.md
```

## 📋 Application Form Includes

* Full Name
* Email Address
* Phone Number
* Job Position
* Experience
* Resume Upload
* Cover Letter
* Submit Button

## 📱 Responsive Design

The webpage is designed to work across different screen sizes:

* 💻 Desktop
* 📱 Mobile
* 📱 Tablet

CSS media queries are used to adapt the layout for smaller screens.

## ♿ HTML Best Practices

This project follows good HTML practices, including:

* Semantic HTML5 elements such as `<header>`, `<main>`, `<section>`, and `<footer>`
* Proper heading hierarchy
* `<label>` elements associated with form inputs
* Meaningful `name` and `id` attributes
* Appropriate input types such as `email`, `tel`, and `file`
* Required fields using the `required` attribute
* Descriptive `alt` text for images where applicable
* Clean and readable code structure
